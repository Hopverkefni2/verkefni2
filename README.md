# TÍNT

TÍNT er vefsíða sem kynnir íslensk fyrirtæki og hjálpar fólki að finna verslanir, vörur og þjónustu á Íslandi á einum stað.

Þetta er hópverkefni í Vefþróun í Tækniakademíunni, haust 2026.

## Síður

| Síða | Skrá | Lýsing |
|---|---|---|
| Forsíða | `index.html` | Hetjusvæði, flokkar, fyrirtæki vikunnar, fréttabréf og um okkur |
| Uppáhald | `favorites.html` | Fyrirtæki sem notandinn hefur vistað, með síum eftir flokkum |
| Sækja um | `saekja-um.html` | Umsóknarform fyrir fyrirtæki sem vilja vera með í TÍNT |

## Virkni

- Skalast að öllum skjástærðum, frá síma upp í stóran skjá
- Skráning á fréttabréf með staðfestingu á netfangi
- Síun á uppáhaldsfyrirtækjum eftir flokkum og hægt að fjarlægja fyrirtæki úr uppáhaldi
- Umsóknarform með villuboðum og upphleðslu mynda (dregið og sleppt)
- Sami haus og fótur á öllum síðum

> Athugið: Engin gögn eru send á netþjón. Form sýna aðeins staðfestingarskilaboð.

## Tækni

- HTML, CSS og JavaScript, án ramma (frameworks)
- [Lucide](https://lucide.dev) fyrir tákn
- Google Fonts: **Freeman** (fyrirsagnir) og **Amarna** (meginmál)
- Hönnun unnin í Figma

## Hvernig á að keyra verkefnið

1. Sæktu verkefnið:
   ```
   git clone [slóð á repo]
   ```
2. Opnaðu `index.html` í vafra, eða notaðu **Live Server** viðbótina í VS Code.

Engin uppsetning eða pakkar eru nauðsynleg.
